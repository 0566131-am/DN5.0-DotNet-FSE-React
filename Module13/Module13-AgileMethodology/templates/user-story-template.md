# User Story Template

## Story
As a **[type of user]**,
I want **[goal/desire]**,
so that **[benefit/value]**.

## Acceptance Criteria (Given-When-Then)
```
Given [context/precondition]
When [action taken]
Then [expected outcome]
```
(Add more Given-When-Then blocks if the story has multiple scenarios.)

## INVEST checklist
- [ ] Independent — doesn't depend on another unfinished story
- [ ] Negotiable — details can be discussed, not a rigid spec
- [ ] Valuable — delivers real value to a user or the business
- [ ] Estimable — the team can reasonably size it
- [ ] Small — fits within a single sprint
- [ ] Testable — clear pass/fail criteria exist
