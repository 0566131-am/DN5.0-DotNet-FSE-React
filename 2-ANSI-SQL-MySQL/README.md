# Module 2 - ANSI SQL using MySQL Practice Exercises

Covers: SELECT basics, filtering & sorting, aggregate functions & grouping,
joins & subqueries, DML (INSERT/UPDATE/DELETE), DDL (CREATE/ALTER/DROP),
indexes & constraints.

## Files
- `exercises/00-schema-seed.sql` – creates the practice database & sample data
  (run this first)
- `exercises/01-select-filter-sort.sql`
- `exercises/02-aggregate-grouping.sql`
- `exercises/03-joins-subqueries.sql`
- `exercises/04-dml.sql`
- `exercises/05-ddl.sql`
- `exercises/06-indexes-constraints.sql`

## How to run
Use any of the online SQL editors from the handbook (onecompiler MySQL,
w3schools Try SQL) or a local MySQL instance / MySQL Workbench.
Run `00-schema-seed.sql` first, then work through the numbered files in order.

## How to submit
Push this folder to your personal public GitHub repo and share the URL.
