# Module 1 - CSS3 Practice Exercises

Covers: Introduction & Including CSS, Selectors, Styling (color, background,
fonts, text, links, lists, tables), Box Model, Media Queries & RWD.

## Files
- `exercises/index.html` – markup shared by all exercises
- `exercises/01-selectors.css` – universal, type, id, class, grouping selectors
- `exercises/02-styling.css` – color, background, fonts, text, links, lists, tables
- `exercises/03-box-model.css` – margin, padding, border, outline, visibility vs display
- `exercises/04-responsive.css` – media queries, responsive layout

Open `exercises/index.html` and link each CSS file one at a time (or all
together) to see the effects, then edit the TODOs.

## How to submit
Push this folder to your personal public GitHub repo and share the URL.
