# Module 1 - HTML5 Practice Exercises

Covers: Introduction, Elements & Attributes, Navigation, Events, Web Forms 2.0,
Web Storage, Web SQL Database, Geolocation.

## Files
- `exercises/01-structure-elements.html` – doctype, semantic tags, lists, tables, forms, id vs class
- `exercises/02-navigation.html` – nav tag, anchor links, in-page section references
- `exercises/03-events.html` – onclick, onchange, onblur, key/mouse events
- `exercises/04-web-forms2.html` – input types, placeholder, autofocus, required, output element
- `exercises/05-web-storage.html` – localStorage vs sessionStorage, delete storage
- `exercises/06-geolocation.html` – Geolocation API, error handling, position options

## How to run
Open any `.html` file directly in Chrome, or use the online editors listed in the
handbook (w3schools tryit, onecompiler, jsfiddle).

## How to submit
1. Solve/extend the TODOs marked in each file.
2. Push this folder to your personal public GitHub repo.
3. Share the repo URL with the POC on demand.
