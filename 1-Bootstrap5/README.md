# Module 1 - Bootstrap 5 Practice Exercises

Covers: Setup, Grid System, Components (typography, forms, buttons, navbar,
cards), Utilities, Icons, JS Plugins, Sass customization (conceptual).

## Files
- `exercises/01-grid.html` – responsive grid system, column classes, alignment
- `exercises/02-components.html` – navbar, forms, buttons, cards, media objects
- `exercises/03-utilities.html` – spacing, colors, borders, shadows, display/visibility
- `exercises/04-js-plugins.html` – modal, dropdown, carousel

All files load Bootstrap 5 from the CDN, so an internet connection is
needed when opening them (no local install required).

## How to submit
Push this folder to your personal public GitHub repo and share the URL.
