# Module 1 - JavaScript Practice Exercises

Covers: Basics, Control Flow, Functions & Scope, Objects & DOM, Arrays,
Asynchronous JS, ES6+ Features, Forms/Fetch API, Debugging basics.

## Files
- `exercises/01-basics.js` – data types, operators
- `exercises/02-control-flow.js` – conditionals, loops, error handling
- `exercises/03-functions-scope.js` – functions, closures, higher-order functions
- `exercises/04-objects-dom.html` + `.js` – objects, DOM manipulation, events
- `exercises/05-arrays.js` – array methods (map, filter, reduce, etc.)
- `exercises/06-async.js` – callbacks, Promises, async/await
- `exercises/07-es6-features.js` – let/const, destructuring, spread/rest, template literals
- `exercises/08-fetch-api.html` + `.js` – Fetch API with a public test endpoint

## How to run
Run the `.js` files with Node.js (`node 01-basics.js`) or open the `.html`
files in a browser with the console open.

## How to submit
Push this folder to your personal public GitHub repo and share the URL.
