# Module 1 - jQuery Practice Exercises

Covers: Library inclusion, the $() function, jQuery methods, DOM
manipulation, events, event helpers.

## Files
- `exercises/01-selectors-methods.html` – $() selectors, content/attribute/CSS/class methods
- `exercises/02-dom-manipulation.html` – append/prepend/remove/clone
- `exercises/03-events.html` – click(), hover(), submit(), event helpers (.on(), .off())

jQuery is loaded from the CDN, so an internet connection is needed.

## How to submit
Push this folder to your personal public GitHub repo and share the URL.
